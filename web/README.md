# Creative Engine Web

桌面端 AI 制片画布的公司网页版本。画布是流程权威：上传、生成、续拍、拉片和审片结果先写入节点，只有用户点击“保存到资产库”才创建资产库副本。

## 本地验证

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run lint
npm test
```

`npm test` 会先完成生产构建，再验证桌面节点注册表覆盖和页面服务。

## 接入公司控制层

复制 `.env.example` 为 `.env.local`：

```env
NEXT_PUBLIC_CONTROL_PLANE_URL=/control
```

同域部署时让反向代理把 `/control/*` 转发到 `server` 服务并移除 `/control` 前缀。也可以填写同站点的 API 子域名；此时服务端 `CEP_PUBLIC_ORIGIN` 必须精确设置为网页正式域名并启用 HTTPS。

未配置控制层地址时，站点只作为私有功能预览，不会提交真实付费任务。配置后使用公司账号密码登录，不开放自助注册。

## 已接通的画布契约

- 桌面 `.cepstudio` 工程、全部桌面节点家族和工作流连线导入。
- 强类型连线、多图逐张用途、导演时间轴、首尾帧、续拍、抽帧和 AI 拉片。
- 七阶段制片的确认、接受风险、暂停、恢复和阶段重做。
- 持久工作流整批预登记额度、严格顺序放行、暂停、恢复、取消、失败重试和个人模板复用。
- 服务端任务报价、幂等提交、进度、暂停、恢复、取消、失败重试和结果节点回写。
- 项目所有者管理编辑、审片和只读成员；多人版本冲突会停止覆盖并要求载入最新版本。
- 管理员逐个创建/批准/停用账号、重置密码、强制会话下线、角色、模型白名单、付费许可、每日任务/额度、并发和审计统计。

安全默认值是“未批准、0 额度、0 并发、无外部模型白名单”。管理员明确确认账号密码、登录状态、额度和引擎后才会放行；白名单留空不代表无限制。

私有 Sites 预览使用平台身份；公司账号密码只会在接入自建控制层后启用。
