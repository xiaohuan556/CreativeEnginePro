# 本地 AI 制片画布

通用创作节点现在使用声明式计划和本机执行器，可组合多个工具，等待上一步结果，再把结果传给后续步骤。无需连接网页 AI 画布服务器。

## 使用

将图片、视频、音频或文本连接到通用创作节点，填写任务后执行。默认规划后自动执行；取消勾选后，先查看画布上的计划，再点击“执行计划”。

示例：

- `把图片统一调整成160x120，然后制作图片轮播`
- `生成一段产品文案，然后生成配音`
- `第一段0.5秒，第二段0.75秒，保留原声，添加字幕：“Hello”，缩放80%，模糊2`

步骤状态和失败原因显示在通用创作节点内，画布只生成实际结果。停止任务会保留已完成结果；输入和参数未改变时，可继续失败或停止的计划。源文件内容变化会使旧计划失效。剪辑结果同时包含成片和可编辑 `.cep` 工程，双击工程结果可在剪辑台继续编辑。

## 本地工具

图片批处理、轮播、混剪、声音分离和图片超分已接入。本地执行生成任务时，使用桌面已有模型配置；图像/视频/语音生成与视觉理解是否联网取决于所配置的模型服务。

- 多图视频完整传递所有图片，提交前检查模型数量限制。
- 超分在独立进程运行；缺模型会报错，不会自动下载模型或把普通插值伪称 AI 超分。工具节点可明确选择传统放大。
- 语义剪辑需要支持视觉的模型，使用带时间戳的采样画面并验证时间线。缺模型或证据不足会明确失败，不宣称已经识别成功。
- 声音分离沿用桌面中心声道滤波能力，不能等同于神经网络分轨。

按用户要求，已删除 AE 控制中心、链接下载、AE 水印/尾页、视频包装和批量智能消除节点及其通用节点执行入口。旧工程打开时会清理这些节点、无功能网页占位节点和任务进度占位卡片，保留实际素材文件及结果。

视频节点的用途设置默认折叠。Ctrl 点击图片会在当前提示词光标处插入 `【图片N】`，紧凑缩略图条用于核对对应图片；补充创意提示词也支持插入。提交时参考资产标签包含相同编号。

## 实现

- `ai/canvas_agent_planner.py`：规则规划、LLM 规划契约、工具与依赖校验。
- `ai/canvas_agent_runtime.py`：依赖执行、取消、恢复、模型任务与输出检查。
- `ai/ui/canvas_agent_worker.py`：后台任务和界面状态传递。
- `ai/canvas_agent_editing.py`：复用剪辑台时间线及导出器的成片执行。
- `core/headless_tools.py`：既有桌面批处理、轮播、混剪、声音分离适配。
- `core/canvas_media_tools.py`：图片超分和传统放大的独立进程执行。

修改在源码中。现有已打包的 EXE 需要重新构建，才能包含这些代码和模板资源。
